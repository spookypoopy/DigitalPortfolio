# Jacob Le — High School Portfolio

This repository contains a one-page portfolio optimized for GitHub Pages. It uses a light, editorial theme suitable for a student profile (academics, clubs, projects, credentials, contact).

## Quick edits (what to replace)
- Replace the placeholder profile image by adding `profile.jpg` to the repo root (72x72 or similar). The site will fall back to a monogram (`JL`) if not present.
- Update contact links in `index.html`:
  - Email: replace the `mailto:` in the `#email-link` anchor.
  - LinkedIn: replace `https://www.linkedin.com/in/your-profile` in the `#linkedin-link` anchor.
  - GitHub: replace `https://github.com/your-username` in the `#github-link` anchor.

## Deploy with GitHub Pages
1. Create a repository named `yourusername.github.io` (or any repo and use the `/docs` folder).
2. Commit these files and push to GitHub.
3. In the repository Settings > Pages, set the Source to `main` branch and Folder to `/ (root)`.
4. Wait a minute — your site will appear at `https://yourusername.github.io/`.
